# 月度数据导入说明

每月初导出上个月的数据，按下面的文件夹放好，运行处理脚本，再在看板管理员入口导入。

## 一、文件夹结构

```
inputs/2026-10/
  autelonline/                 # 三个深度分析站，各一个文件夹（名字固定）
    gsc_performance.zip        # ① GSC 效果报告导出（整月，原样 ZIP）
    gsc_query_page.csv         # ② Looker Studio 查询词 × 着陆页
    ga4_landing.csv            # ③ GA4 着陆页（全部来源，不要预先筛选）
    ga4_acquisition.csv        # ④ GA4 流量获取（来源/媒介 + 渠道组）
    gsc_unindexed_已发现.csv    # ⑤ 未编入索引，文件名里写明原因
    gsc_unindexed_已抓取.csv
    keywords_monitor.csv       # 可选：确认过的关键词监控词表
    ads_search_terms.csv       # 可选：Google Ads 搜索字词（季度）
  launchx431online/            # 同上
  launchx431pro-us/            # 同上
  summary_sites/               # 其余 9 个站
    autel-uk.zip               # 优先：GSC 效果报告 ZIP，文件名用站点 id
    monthly_gsc_manual.csv     # 或者：手工填写点击和曝光（模板见 templates/）
  semrush.csv                  # 12 个站的 Semrush 数据（模板见 templates/）
  blog_articles.csv            # 可选：博客文章清单（网址、标题、上线日期、主题）
  reference/
    launchx431online_keyword_page_mapping.csv   # 关键词归属表，有修改时更新
    autelonline_keyword_page_mapping.csv
```

站点 id：autelonline、autel-uk、autel-eu、launchx431online、launchonline-uk、launchonline-eu、otofix、otofix-uk、otofix-eu、launchpro、launchpro-uk、launchx431pro-us。

## 二、每份文件怎么导出

**① GSC 效果报告**：效果 → 搜索结果，日期选上个月 1 日到最后一天，搜索类型“网页”，右上角“导出 → 下载 CSV”，得到 ZIP，不要解压。总点击、总曝光取自 ZIP 里的“日期”表。

**② 查询词 × 着陆页**：Looker Studio 用 GSC 的“网址展示次数（URL impression）”数据源，维度“查询”“着陆页”，指标“网址点击次数”“展示次数”“网址点击率”“平均排名”，日期选整月，导出 CSV。不要用“网站展示次数”数据源。

**③ GA4 着陆页**：探索 → 自由形式。维度：着陆页 + 查询字符串、会话来源/媒介、会话默认渠道组。指标：会话数、互动率、每次会话的平均互动时长、已查看的商品、加入购物车次数、电子商务购买次数、购买收入。日期选整月，不加来源筛选。导出前看右上角是否显示抽样，有抽样就缩短日期分段导出。

**④ GA4 流量获取**：报告 → 获客 → 流量获取，维度“会话来源/媒介”，添加次级维度“会话默认渠道组”，指标要有会话数、电子商务购买次数（或把关键事件选为 purchase，并在列名里注明 purchase）、总收入。

**⑤ 未编入索引**：编入索引 → 网页，分别点开“已发现 - 尚未编入索引”“已抓取 - 尚未编入索引”，导出网址明细。文件名里写“已发现”或“已抓取”。

**Semrush**：填 templates/semrush.csv。database 写实际用的地区数据库，每个月保持一致；snapshot_date 写数据日期；traffic_metric 写指标名称（如果是月末快照，不要写成月平均）。

## 三、运行和导入

```
python -m pipeline.build --month 2026-10 --input inputs/2026-10 --out out/2026-10 --prev out/2026-09/import.json
```

- 先看 `out/2026-10/report.md`：有“错误”时按提示修正文件后重跑；“提醒”逐条确认。
- `--prev` 填上个月的 import.json，用于环比、下滑页面和关键词上月排名。没有就省略，这几项本月为空。
- 管理员登录看板 → 月度数据表 → 月度数据导入，选择 `out/2026-10/import.json`。
- `out/2026-10/monthly_column.xlsx` 的 D2:D133 就是部门月度表新月份的一列；看板“月度数据表”页的“复制当月数值列”是同样的内容。
- 加 `--draft` 会导入为草稿，只有管理员能看到，核对后再重新导入为公开。

## 四、口径（处理脚本固定执行）

- 自然流量 = Organic Search、Organic Shopping、Organic Social、Organic Video、AI Assistant；AI 来源（chatgpt、perplexity、gemini、claude、copilot 等）无论 GA4 归到哪个渠道都计入 AI Assistant。
- 剔除已确认的 Bing 广告：bing / search_bra、bing / pla。Autel 的 Bing / search 计入自然流量，但标注“待核实”。
- 订单只用购买指标，不用全部关键事件。
- GSC 总量以效果报告为准，不用查询词明细加总。
- 机会清单的阈值写在 `pipeline/config.py`，改阈值只改这一个文件。
